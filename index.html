SyntaxForest Guide & Shortcuts

        
      

      

        
Quick Tree Editing

        
    
          
  • Click node: Select it & open its Node Inspector.
    • 
          
  • Double-click node: Quick-edit its top label inline.
    • 
          
  • Enter: Add a child branch to the selected node.
    • 
          
  • P: Insert a parent branch above the selected node.
    • 
          
  • C: Enter Draw Arrow / Line mode (click source node, then target node).
    • 
          
  • Delete / Backspace: Delete the selected node (when not typing in a field).
    • 
          
  • Ctrl/Cmd + Z / Y: Undo / Redo.
    • 
        

        
Drawing Movement, Agree, Binding & Brackets

        
    
          
  • Switch to Draw Arrow / Line (or press C), click source node, then click target node.
    • 
          
  • In the Arrows tab, switch between Right Angles (-- ++(0, -2em) -|) and Curved (to[out=..., in=...]) or Straight lines, adjust drop depth or angles, set dashed/dotted/solid styles, and add italic labels like Affix Hopping.
    • 
          
  • In Brackets & Notes, toggle a curly brace, square bracket, or box around any subtree with optional vertical dotted guide lines (like Example 14).
    • 
        

        
LaTeX Output Scope

        
The code drawer strictly outputs only \begin{forest} ... \end{forest}, ready to paste directly inside \ex ... \xe in a ling-200b document.
